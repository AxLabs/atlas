# Testing risk matrix

Canonical companion to [testing.md](testing.md). This is **not** a second testing philosophy: it
records which Atlas-owned failure modes are protected, at which level, and what remains residual.

Test Atlas composition and behavior, not upstream libraries.

- Do test: Atlas `Select` composition losing keyboard/trigger size behavior
- Do not test: every internal Base UI Select algorithm

Generated OpenAPI schema files are excluded from line coverage and protected by the deterministic
`pnpm api:check` drift gate.

Issue #16 implements Storybook build, axe/interaction tests, Playwright visual baselines, and the UI
Quality CI workflow. This matrix records how those gates map to critical components.
