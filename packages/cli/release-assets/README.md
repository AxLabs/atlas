# Production release assets

Canonical production snapshots consumed by installed `@blitzcraftlabs/atlas` during `atlas upgrade`.

These directories are **not** the repository-local rehearsal pair under `releases/0.1.0` and
`releases/0.2.0`. Rehearsal fixtures stay rehearsal-only and are never packaged as public upgrade
support.

| Path | Role |
| ---- | ---- |
| `production/<version>/` | Full production snapshot generated from that Atlas release tree |
| Packaged `assets/releases/` | Support-window subset copied into the npm CLI at build time |

Generation:

- Historical `0.4.0` was reconstructed from the canonical `v0.4.0` tag, not from later `main`.
- Future versions are generated by `pnpm changeset:version` after package versions advance.
- Generation builds `@atlas/project` first so it works after `pnpm install --frozen-lockfile` without a prior workspace `dist/`.
- Existing snapshots are not overwritten unless `--replace` is passed.

See `docs/how-we-build/upgrades.md`.
